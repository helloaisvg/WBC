# 机器人全身运动规划与 REMANI-Planner 学习报告

## 第一部分：全身运动规划框架与前置算法基础

### 一、 移动操作机器人全身运动规划总览

#### 1. 整体流水线

**0.** **任务定义**

**1.** **建模表示**

**1A 机器人模型**：底盘与机械臂运动学、动力学、关节限制、碰撞几何

**1B 环境模型**：地图、障碍物、距离场（SDF/ESDF）、障碍物运动状态

**2.** **全身路径规划（找一条可行的路）**

搜索可行的底盘位姿与机械臂关节运动组合（A\*、State Lattice、RRT、RRT\*、环境自适应搜索）

**3.** **全身轨迹生成与优化（让路真能执行）**

把可行路径优化为满足时间、平滑性、碰撞和运动约束的连续轨迹（Spline、MINCO、CHOMP、TrajOpt、SQP/数值优化）

**4.** **轨迹执行与全身控制（怎么真做到）**

跟踪参考轨迹，协调底盘和机械臂，处理实时误差（MPC、HQP、Whole-Body Control）

**5.** **执行反馈与重规划**

更新机器人状态与环境，检测偏差或新障碍物，必要时触发重规划

#### 2. 各环节核心定义

**1.** **任务定义：** 底盘到达特定区域，机械臂在移动过程中保持特定姿态或避开障碍区域，按要求完成抓取、移动、放置。

**2.** **机器人构型空间（C-space）：** 对“底盘 + $n$ 轴机械臂”系统，全身构型表示为：

```math
q = [x_b, y_b, \theta_b, q_1, \dots, q_n]^T
```

其中 $x_b, y_b, \theta_b$ 为底盘平面位置与朝向， $q_1, \dots, q_n$ 为机械臂关节变量。

**3.** **全身路径规划：** 求从初始构型到目标构型的无碰撞路径。

**图搜索类：** Dijkstra、A\*、Hybrid A\*、State Lattice（状态栅格）。

**采样类：** PRM、RRT、RRT\*、RRT-Connect、Informed RRT\*。

**专用搜索器：** 结合机器人结构、环境特征或任务需求定制搜索策略（REMANI 的分层受限搜索 + 局部全身修复）。

**4.** **全身轨迹优化：** 同时关注位置、速度、加速度与加加速度（Jerk），例：

```math
\min_{q(t), T} J_{\text{smooth}} + \lambda_c J_{\text{collision}} + \lambda_d J_{\text{dynamic}} + \lambda_t J_{\text{time}}
```

```math
\text{s.t.} \quad q(0) = q_0, \quad q(T) = q_{\text{final}}
```

其中 $q(t)$ 为随时间变化的轨迹， $T$ 为总时长， $\lambda$ 为各项权重：

$J_{\text{smooth}}$（平滑代价）：惩罚加速度、加加速度的平方积分。

$J_{\text{collision}}$（碰撞代价）：不撞（环境障碍与自碰撞）。

$J_{\text{dynamic}}$（动力学/运动学代价）：不超速、硬拐、超关节限位。

$J_{\text{time}}$（时间代价）。

**5.** **轨迹执行与全身控制：** 规划出的轨迹只是参考，要考虑跟踪控制。模型预测控制（MPC）、分层二次规划（HQP）与任务优先级控制。

### 二、 前置核心算法补充

#### 1. Hybrid A\*

普通 A\* 在离散栅格（grid）上搜索线；Hybrid A\* 在连续空间中搜索真实平滑轨迹，每个节点状态包含坐标、航向角与曲率 $q = (x, y, \theta, \kappa)$，每次扩展通过运动学模型生成一段连续轨迹。

**离散网格去重（剪枝）：** 把连续状态空间划分成网格，两条连续轨迹最终落在同一网格内，只保留代价值更小的那条，压缩搜索空间。

**复合启发式** $f = g + h$： $h$ 取**非完整约束启发式和障碍物启发式**的**最大值**：

**非完整约束启发式：** 忽略障碍物、仅考虑底盘运动学约束（如最小转弯半径）算出的到终点的最短平滑曲线长度。

**障碍物启发式：** 忽略运动学约束，直接在栅格地图上用传统 2D A\* 算出的到终点的避障最短距离。

#### 2. State Lattice（状态栅格）

解决传统栅格搜索出的路径无法执行的问题：

**节点：** 空间位置 $(x, y)$ + 姿态信息（航向角 $\theta$、曲率 $\kappa$）。

**边：** **运动基元（Motion Primitives）**，即从合法控制输入生成的连续可行短轨迹。

#### 3. PRM（Probabilistic Roadmap，概率路线图）

采样类，在空间中随机采样点，将相邻可行点连接起来构成 roadmap，适合高维机械臂（随机采样防计算爆炸）。

**1.** **建图阶段：** 随机撒点（落在障碍物上的直接丢） $\rightarrow$ 找邻居（看周围有哪些其他采样点） $\rightarrow$ 连线碰撞测试（当前点与邻居连线，连线穿障碍物废弃，没穿保留这条边） $\rightarrow$ 生成网络。

**2.** **查询阶段：** 将起点、终点接入 Roadmap，用 A\* 或 Dijkstra 搜索最短路径。建好图后单次查询很快。

**缺点：** 随机采样路径可能不平滑，可能无路，可能真跑不了。

#### 4. RRT 系列（快速扩展随机树）

**RRT（单向单次查询）：** 从起点开始向随机方向快速生长探索树。

**1.** **撒点（Sample）：** 在空间随机采样 $x_{\text{rand}}$。

**2.** **找近（Nearest）：** 在当前树上找离 $x_{\text{rand}}$ 最近的节点 $x_{\text{near}}$。

**3.** **迈步（Steer）：** 从 $x_{\text{near}}$ 朝 $x_{\text{rand}}$ 方向前进固定步长，得到 $x_{\text{new}}$。

**4.** **避障（Collision Check）：** 检查 $x_{\text{near}} \rightarrow x_{\text{new}}$ 连线是否碰撞；无碰则将 $x_{\text{new}}$ 加入树，碰撞则放弃。

**特性：** **概率完备**（只要可行路径存在，树必能长到）。树末分叉多，易让随机点落在空旷区域概率大（树根密）。

**RRT-Connect：** 双向 RRT，从起点和终点同时种两棵树，每轮扩展后让另一棵树贪心向新节点连续迈步尝试接通，大幅加速。

**RRT\*：** 原版 RRT 找到路径即停；RRT\* 加入**重连（Rewire）**，看新节点周围有无其它节点绕过去比原来近，就断开原来的。

**Informed RRT\*：** RRT\* 重连查得太多了，最优路径必然比直线长、比当前解短，把比当前长的区域直接不扫了，在以起终点为焦点的椭圆内随机找点（跟两端点连线总长小于长轴），随最优解向内收缩提速。

#### 5. Spline（样条曲线）与 B-Spline

为避免单一高阶多项式拟合长轨迹引发剧烈震荡的**龙格现象**，工程上采用多段低阶多项式分段拼接：

**普通分段样条：** 每段用低阶多项式 $p(t) = a t^3 + b t^2 + c t + d$ 表示，拼接点处强制前后两段的位置、速度、加速度相等。**缺点：** 曲线必须穿过给定路点，改动中间任意一个路点，整条曲线都会发生全局形变。

**B-Spline（B 样条）：** 由**控制点**（可以不经过）决定形状，核心优势是**局部支撑性**。移动某一个控制点，只会改变其附近的局部曲线段。

#### 6. MINCO

解耦，将轨迹的**空间形状与时间分配拆分**：

变量是路点 $q$ 和时间 $T$，在 $T_i$ 经过 $q_i$，MINCO 通过解析映射直接反推出满足最小控制量的多项式系数。

第 $i$ 段轨迹表示为随时间变化的多项式 $p_i(t) = c_0 + c_1 t + c_2 t^2 + \dots$，求导直接得到速度 $\dot{p}_i(t)$ 与加速度 $\ddot{p}_i(t)$，只要确定系数就能求各时刻状态。

求参过程：输入（中间航点、每段时长、起终边界条件） $\rightarrow$ 线性映射求系数，具体见下：

**核心系数映射：** 将**中间必经航点** $q$ 与**各段持续时长** $T$ 作为优化变量。针对最小控制努力（Minimum Control Effort）问题：

```math
\min_{p(t)} \int_{t_0}^{t_m} p^{(s)}(t)^T W p^{(s)}(t) \, dt
```

构造带状线性方程组 $M(T) c = b(q)$，直接解出多项式系数 $c = \mathcal{M}(q, T)$，优化时再通过链式法则将目标函数对 $c$ 的梯度传回 $(q, T)$。

**算例：**

设单关节在 $2\text{ s}$ 内从 $0\text{ rad}$ 转至 $1\text{ rad}$，固定在 $t = 1\text{ s}$ 经过中间点 $m = 0.4\text{ rad}$，且起终点静止（速度、加速度均为 $0$）。采用两段五次多项式参数化（各自使用局部时间 $t \in [0, 1]$ 与 $\tau = t - 1 \in [0, 1]$）：

```math
p_1(t) = c_0 + c_1 t + c_2 t^2 + c_3 t^3 + c_4 t^4 + c_5 t^5, \quad t \in [0, 1]
```

```math
p_2(\tau) = d_0 + d_1 \tau + d_2 \tau^2 + d_3 \tau^3 + d_4 \tau^4 + d_5 \tau^5, \quad \tau \in [0, 1]
```

**1.** **清点约束与剩余自由度**（ $12 \rightarrow 2$）：

两段共 $6 + 6 = 12$ 个待定系数，已知硬约束共 $10$ 个方程：

**起点边界**（ $3$ 个）： $p_1(0) = 0, \quad \dot{p}_1(0) = 0, \quad \ddot{p}_1(0) = 0$（直接推出 $c_0 = c_1 = c_2 = 0$）；

**终点边界**（ $3$ 个）： $p_2(1) = 1, \quad \dot{p}_2(1) = 0, \quad \ddot{p}_2(1) = 0$；

**中间点连接**（ $4$ 个）：第一段末端和第二段起点位置都必须等于 $m$（ $p_1(1) = m, \quad p_2(0) = m$，共 $2$ 个），外加中间点速度连续（ $\dot{p}_1(1) = \dot{p}_2(0)$， $1$ 个）、加速度连续（ $\ddot{p}_1(1) = \ddot{p}_2(0)$， $1$ 个）。

因此剩余自由度为 $12 - 10 = 2$ 个，正好对应中间点的未知速度 $v_m$ 和未知加速度 $a_m$。一旦给定 $(m, v_m, a_m)$，线性联立即可把 $c_3, c_4, c_5$ 和 $d_0 \sim d_5$ 全部唯一表示出来。

**2.** **分段求三阶导（Jerk）平方积分：**

最小化 Jerk（取 $s = 3$），对两段分别求三阶导数：

```math
p_1^{(3)}(t) = 6c_3 + 24c_4 t + 60c_5 t^2, \quad p_2^{(3)}(\tau) = 6d_3 + 24d_4 \tau + 60d_5 \tau^2
```

利用幂函数积分公式 $\int_0^1 t^n \, dt = \frac{1}{n+1}$，分别展开平方并在 $[0, 1]$ 上积分得到关于 $(c_3, c_4, c_5)$ 和 $(d_3, d_4, d_5)$ 的二次型；再把由 $(m = 0.4, v_m, a_m)$ 解出的系数代回，两段积分相加得到总平滑代价：

```math
J(v_m, a_m) = \int_0^1 p_1^{(3)}(t)^2 \, dt + \int_0^1 p_2^{(3)}(\tau)^2 \, d\tau = 384 v_m^2 - 720 v_m + 18 a_m^2 - 24 a_m + 374.4
```

**3.** **极值消元**（为什么不用管 $v_m, a_m$）：

如果强制每段“到点停下”（令 $v_m = 0, \quad a_m = 0$），代价高达 $J = 374.4$；

允许平滑连续通过，直接对 $v_m, a_m$ 求偏导置零（ $\frac{\partial J}{\partial v_m} = 0, \quad \frac{\partial J}{\partial a_m} = 0$），解得最优中间状态 $v_m = 0.9375\text{ rad/s}, \quad a_m = \frac{2}{3}\text{ rad/s}^2$，此时最小代价骤降至 $J_{\min} = 28.9$。

**对应回 MINCO 映射：** 在固定航点 $m$ 与时长 $T$ 时，令控制努力积分取极值，数学上等价于在中间点自动补齐了高阶导数连续条件（三阶 Jerk 连续与四阶 Snap 连续，恰好补足最后 $2$ 个线性方程，凑满 $10 + 2 = 12$ 个方程）。所以 MINCO 只需输入航点位置 $q$ 和时间 $T$，就能通过 $M(T)c = b(q)$ 一步算出最优系数 $c$，无需把各阶导数塞进优化变量。

**4.** **放开中间位置** $m$（平滑性与避障的权衡）：

若把中间位置从固定的 $0.4$ 改为待优化变量 $m$，按同上步骤消去 $(v_m, a_m)$ 后，整条轨迹的最小 Jerk 代价只剩 $m$ 的函数：

```math
J_{\min}(m) = 22.5 + 640(m - 0.5)^2
```

无障碍物时，优化器自然收敛到中点 $m = 0.5$（最平滑， $J = 22.5$）；若 $0.5$ 附近存在障碍物，后端总目标里的避障惩罚项会把 $m$ 推偏（例如挤到 $0.4$），本质就是牺牲一点平滑代价来换取不碰撞。

#### 7. CHOMP（基于协变梯度的轨迹优化）

把整条离散路点轨迹 $\xi = (q_1, q_2, \dots, q_n)^T$ 看作高维空间中的一个点，最小化综合成本：

```math
U(\xi) = f_{\text{prior}}(\xi) + f_{\text{obs}}(\xi)
```

**平滑先验项** $f_{\text{prior}}(\xi)$：构造二次型 $f_{\text{prior}}(\xi) = \frac{1}{2} \xi^T A \xi + b^T \xi + c$，梯度为线性 $\nabla f_{\text{prior}} = A \xi + b$。利用**有限差分矩阵**近似导数：

**一阶差分（近似速度）：** 以三点为例，差分矩阵定义为：

```math
D_1 = \left[-1,\ 1,\ 0;\ 0,\ -1,\ 1\right]
```

对应：

```math
\frac{1}{2}\Vert D_1 \xi \Vert_2^2 = \frac{1}{2}\left[(q_2 - q_1)^2 + (q_3 - q_2)^2\right] = \frac{1}{2} \xi^T (D_1^T D_1) \xi
```

因此 $A = D_1^T D_1$。

**二阶差分（近似加速度）：**

```math
D_2 = \left[1,\ -2,\ 1\right], \qquad D_2 \xi = q_1 - 2q_2 + q_3
```

```math
\frac{1}{2}\Vert D_2 \xi \Vert_2^2 = \frac{1}{2}\xi^T (D_2^T D_2)\xi
```

因此 $A = D_2^T D_2$。

**关于对称正定性：** 纯差分构造的 $A = D^T D$ 是对称半正定矩阵；在固定起终点边界条件（消去平移/常速零空间）或加入正则化使 $A$ **对称正定**的前提下，满足：(1) $A^{-1}$ 存在；(2) $\frac{1}{2}\xi^T A \xi$ 严格凸，有唯一最小值；(3) 可直接用 Cholesky 分解高效求解线性方程组，无需显式求逆。

**障碍惩罚项** $f_{\text{obs}}(\xi)$：在 3D 物理空间预建符号距离场（SDF），对机器人包络体采样点查询离障距离，越近成本越高。

**协变梯度更新：**

```math
\xi_{k+1} = \xi_k - \frac{1}{\lambda} A^{-1} \nabla U(\xi_k)
```

区别于普通梯度下降 $-\alpha g$，左乘预条件矩阵 $A^{-1}$ 相当于在平滑度量下走最速下降方向——当某个局部路点被障碍物排斥推开时， $A^{-1}$ 会把局部排斥力平滑地分摊扩散到整条轨迹上，保持整体形变自然。

#### 8. STOMP（随机轨迹优化）

概率化的 CHOMP，用**带噪轨迹随机采样 + 代价加权平均**替代梯度求导（最大优势：**不要求代价函数可微**，可直接塞入非光滑碰撞检测、力矩限制、姿态约束等任意黑盒代价）：

**1.** **平滑噪声采样：** 从当前轨迹 $\theta$ 出发，生成 $K$ 条候选轨迹 $\hat{\theta}_k = \theta + \epsilon_k$，其中噪声 $\epsilon_k \sim \mathcal{N}(0, R^{-1})$， $R = D_2^T D_2$（固定端点或正则化保证可逆，采样出的噪声本身就是平滑曲线）。

**2.** **逐点评估代价：** 对每条候选轨迹的每个时间步 $i$ 计算局部代价 $S(\hat{\theta}_{k,i})$。

**3.** **Softmax 转概率权重**（代价越低的轨迹段权重越高）：

```math
P(\hat{\theta}_{k,i}) = \frac{\exp\left(-\frac{1}{\lambda} S(\hat{\theta}_{k,i})\right)}{\sum_{l=1}^K \exp\left(-\frac{1}{\lambda} S(\hat{\theta}_{l,i})\right)}
```

**4.** **加权平均求期望扰动：** $\delta \theta_i = \sum_{k=1}^K P(\hat{\theta}_{k,i}) [\epsilon_k]_i$。

**5.** **平滑投影：** 各时间步独立加权拼出的扰动可能不够连贯，乘上列归一化的平滑矩阵 $M = \mathrm{colnorm}(R^{-1})$ 做平滑投影： $\delta \theta \leftarrow M \delta \theta$。

**6.** **迭代更新：** $\theta \leftarrow \theta + \delta \theta$，重复上述过程直至收敛。

#### 9. TrajOpt（顺序凸优化轨迹规划）

将运动规划直接建模为带非线性约束的优化问题：

```math
\min_{\xi} f(\xi) \quad \text{s.t.} \quad g(\xi) \le 0
```

其中 $f(\xi)$ 为路径长度或平滑度代价， $g(\xi)$ 为避障、关节限位等非线性约束。采用 **SQP（顺序二次规划）+ 信任域（Trust Region）** 求解：

**1.** **局部凸化：** 在当前轨迹附近的信任域内，对目标函数做二次近似，对非线性约束（如碰撞距离）做一阶仿射线性化。

**2.** **连续时间扫掠体积碰撞（Swept-volume Collision）：** 不只检查离散路点，而是计算相邻两路点之间机器人刚体凸包扫掠体积与障碍物的有向距离，确保路点较稀疏时中间过渡段也绝不穿模。

**3.** **精确软约束惩罚（Hinge Penalty）：** 把避障约束转为违反安全距离时的精确惩罚项（距离大于安全阈值时惩罚严格为零）。

**4.** **求解凸 QP 子问题：** 在信任域内解出一步更新量并调整信任域大小，循环迭代至收敛。

#### 10. HQP（Hierarchical Quadratic Programming，分层二次规划）

用于全身瞬时控制（WBC）的**硬性优先级求解器**：高优先级任务拥有绝对优先权，低优先级任务只能在不劣化高优先级最优解的零空间内寻找次优解。

决策变量通常取全身关节/底盘速度：

```math
z = [\dot{q}_1, \dot{q}_2, \dots, \dot{q}_n]^T
```

在小步长内，末端任务速度与关节速度呈线性关系：

```math
v_{\mathrm{task}} \approx A z
```

期望任务值为 $b$，任务跟踪误差为 $A z - b$，物理限幅不等式为 $C z \le d$。

**逐层嵌套求解：**

**第** $1$ **层（最高优先级，如安全限位/避障/平衡）：**

```math
z_1^* = \arg\min_z \Vert A_1 z - b_1 \Vert_2^2 \quad \text{s.t.} \quad C z \le d
```

**第** $2$ **层（次高优先级，如末端位姿跟踪）：** 新增等式约束 $A_1 z = A_1 z_1^*$ 锁死第 $1$ 层的最优任务表现：

```math
z_2^* = \arg\min_z \Vert A_2 z - b_2 \Vert_2^2 \quad \text{s.t.} \quad A_1 z = A_1 z_1^*, \quad C z \le d
```

**第** $L$ **层（低优先级，如姿态保持/关节居中）：**

```math
z_L^* = \arg\min_z \Vert A_L z - b_L \Vert_2^2 \quad \text{s.t.} \quad A_k z = A_k z_{L-1}^* \quad (\forall k < L), \quad C z \le d
```

> 注：全身路径规划和轨迹生成的算法学的时候比较直觉易懂，像有限差分那种构造协变来优化学的比较吃力数学略难但也能想通，这个笔记是根据初版我的手稿的转录而成，手稿记录在 https://github.com/helloaisvg/WBC/notes/handwritten

## 第二部分：REMANI-Planner

**论文：** *Real-time Whole-body Motion Planning for Mobile Manipulators Using Environment-adaptive Search and Spatial-temporal Optimization*

**背景：**

只搜底盘或折起机械臂：保守、浪费操作自由度；底盘 + 机械臂全维一起采样：耗时不可控、难以实时。

**REMANI 流水线：** Hybrid A\* 搜底盘 $\rightarrow$ 沿底盘路点分层搜机械臂（Multilayer Constrained RRT\*-Connect） $\rightarrow$ 特殊情况窄道断连处局部全身重搜 $\rightarrow$ MINCO 时空轨迹优化。

### 一、 模型（Sec. III）

#### 1. 状态

**系统原状态**（ $3+\mathcal{L}$ 维）： $x = [x_b^T, q_m^T]^T$，其中差速底盘状态 $x_b = [q_x, q_y, \psi]^T = [q_b^T, \psi]^T$，机械臂关节角 $q_m = [q_1, \dots, q_{\mathcal{L}}]^T$；速度控制输入 $u = [\omega_l, \omega_r, \dot{q}_m^T]^T$。

**后端规划空间降维**（ $2+\mathcal{L}$ 维）：仅优化广义坐标 $q = [q_b^T, q_m^T]^T \in \mathbb{R}^{2+\mathcal{L}}$（省去底盘朝向 $\psi$），利用差速底盘微分平坦性，由平面位置导数与前进/倒车标志 $\eta \in \{-1, 1\}$ 直接反解朝向、左右轮角速度 $\omega_{l(r)}$ 与轮角加速度 $\alpha_{l(r)}$：

```math
\psi = \mathrm{atan2}(\eta \dot{q}_y, \eta \dot{q}_x)
```

```math
\omega_{l(r)} = \frac{1}{2r_w}\left(2\eta \Vert \dot{q}_b \Vert_2 \mp d_w \omega_b\right), \quad \alpha_{l(r)} = \frac{1}{2r_w}\left(2\eta \frac{\dot{q}_b^T \ddot{q}_b}{\Vert \dot{q}_b \Vert_2} \mp d_w \alpha_b\right)
```

其中 $r_w$ 为车轮半径， $d_w$ 为轮距， $\omega_b, \alpha_b$ 为底盘角速度与角加速度（推导 $\alpha_b$ 会用到位置三阶导 $q_b^{(3)}$）。

#### 2. 全身多球体碰撞包络

将底盘（记为连杆 $0$）和 $\mathcal{L}$ 个机械臂连杆统一包络为碰撞球集合。连杆 $l$ 上第 $m$ 个碰撞球（半径 $r_l$）球心的世界系坐标由正向运动学给出：

```math
{}^{\mathcal{W}}p_{l,m} = {}^{\mathcal{W}}T_l \, {}^lp_{l,m}, \quad \forall l \in \{0, 1, \dots, \mathcal{L}\}, \quad \forall m \in \{1, \dots, m_l\}
```

### 二、 前端：环境自适应路径搜索（Sec. IV）

常态下拆分为 $\mathbb{R}^3$（底盘）+ $\mathbb{R}^{\mathcal{L}}$（机械臂）两个低维空间串行快搜；遇到窄道死锁时，仅在局部断口退化回 $\mathbb{R}^{3+\mathcal{L}}$ 全身联合搜索以保证完备性。

#### 1. 底盘初搜与按正倒车分段接口（Hybrid A\*）

用 Hybrid A\* 搜出底盘无碰路径后，**按前进/倒车换向点切分为** $N$ **个单向子段**：

```math
\mathcal{P}_b = [P_{b,1}, \dots, P_{b,N}]
```

第 $i$ 子段包含离散路点序列 $P_{b,i} = \{Q_{b,i,1}, \dots, Q_{b,i,M_i+1}\}$，其中 $Q_{b,i,j} = [p_x, p_y, \psi] \in \mathbb{R}^3$。

向下一级输出三元组：底盘路点集 $\mathcal{P}_b$、子段运动方向标志 $\eta = \{\eta_1, \dots, \eta_N\}$（ $\eta_i \in \{-1, 1\}$）、初始时间分配 $T = [T_1^T, \dots, T_N^T]^T$（ $T_i \in \mathbb{R}^{M_i}$）。

#### 2. Multilayer Constrained RRT\*-Connect（机械臂分层受限搜索）

将有序的底盘离散路点视作“层”，在固定每层底盘位姿的前提下搜索机械臂构型 $Q_{m,i,j} \in \mathbb{R}^{\mathcal{L}}$。相比标准双向 RRT\*-Connect，加了一个分层：

**节点绑定层号：** 树节点定义为 $x = (q_m, h)$， $h$ 为对应的底盘路点层号；起终两棵树交替采样与连接。

**受限扩展 `EXTEND*`：**

**1.** `SAMPLE`：随机抽取机械臂构型与层号 $x_{\text{rand}} = (q_{m,\text{rand}}, h_{\text{rand}})$。

**2.** `NEAREST`：在当前生长树中查找最近节点 $x_{\text{nearest}} = (q_{m,\text{nearest}}, h_{\text{nearest}})$。

**3.** `STEER`：受底盘路点先后顺序限制，新节点 $x_{\text{new}}$ **强制落在相邻下一层** $h_{\text{nearest}} + 1$。

**4.** `Rewire`：**仅在相邻层**节点之间尝试重连以缩短关节路径长度。

**逐层 `CONNECT`：** 另一棵树的最近节点逐层（layer by layer）向 $x_{\text{new}}$ 生长连接并在经过的层留下新节点；一旦某层连线碰撞则终止当前连接，交换两棵树角色进入下一轮采样。

#### 3. 断连局部全身重搜（Local Whole-body Path Searching）

**触发条件：** 在矮桥洞、窄门框等复杂区域，Hybrid A\* 给出的底盘路线可能贴障碍物过近，导致机械臂怎么摆都撞，两棵分层搜索树在中间层段彻底卡死出现断口（interrupted part）。

**多起点-多终点局部打通：**

**1.** 保留断口两侧已经搜好的树分支，收集两侧树末端的多个机械臂状态，分别与该层对应的底盘状态合并（`Merge`），还原成 $\mathbb{R}^{3+\mathcal{L}}$ 全身状态。

**2.** 将断口修复建模为 $\mathbb{R}^{3+\mathcal{L}}$ 空间下的**多起点-多终点（Multi-start, Multi-goal）全身规划问题**，调用标准 RRT\*-Connect 局部求解（允许底盘微调绕行配合机械臂低头钻过），接通后拼回完整路径。

### 三、 后端：MINCO 时空轨迹优化（Sec. V）

#### 1. 分段多项式表示与无约束转录目标

与前端切出的 $N$ 个正/倒车子段一一对应，整条全身轨迹划分为 $N$ 段；第 $i$ 段由 $M_i$ 拍、 $(2+\mathcal{L})$ 维、 $2s-1$ 次分段多项式构成：

```math
q_{i,j}(t) = c_{i,j}^T \beta(t - \overline{T}_{i,j-1}), \quad t \in [\overline{T}_{i,j-1}, \overline{T}_{i,j}], \quad \beta(t) = [1, t, \dots, t^{2s-1}]^T
```

其中系数矩阵 $c_{i,j} \in \mathbb{R}^{2s \times (2+\mathcal{L})}$，累计时间戳为：

```math
T^{\mathrm{cum}}_{i,j} = \sum_{k=1}^j T_{i,k}
```

利用 MINCO 解耦优化变量与采样点规模，并通过约束转录将不等式约束化为软惩罚求解（原文公式 3、4）：

```math
\min J = \sum_{i=1}^N \left( J_{s,i} + J_{T,i} + J_{p,i} \right)
```

**控制努力平滑项：** $J_{s,i} = \int_0^{T_i} q_i^{(s)}(t)^T q_i^{(s)}(t) \, dt$

**总耗时正则项：** $J_{T,i} = \omega_T T_i$（其中 $T_i = \Vert T_i \Vert_1$）

**不等式违反惩罚项：**

```math
J_{p,i} = \sum_{j=1}^{M_i} \sum_{d \in \mathcal{D}} \omega_d I_\Sigma\left(\mathcal{G}_d(q_{i,j})\right)
```

其中 $I_\Sigma(\cdot)$ 采用**疏密混合采样策略（sparse and dense sampling）**，在强非线性约束段加密采样点以加快优化收敛。

#### 2. 三类约束 $\mathcal{G}_d \le 0$

**1.** **安全性约束（Safety）**

**ESDF 环境避障：** 球心处距离场读数须大于球半径（底盘朝向依赖 $\dot{q}_b$，故球心位置是 $(q, \dot{q}_b)$ 的函数）：

```math
\mathcal{G}_{s_o}(q, \dot{q}_b) = r_l - D_{\text{ESDF}}\left({}^{\mathcal{W}}p_{l,m}(q, \dot{q}_b)\right) \le 0
```

**全身自碰撞：** 直接在连杆 $l'$ 局部坐标系下计算球心距，**仅与机械臂关节角** $q_m$ **有关**，与底盘位姿无关，减少求导计算量：

```math
\mathcal{G}_{s_c}(q_m) = r_{l'} + r_l - \Vert {}^{l'}p_{l',i} - {}^{l'}T_l \, {}^lp_{l,j} \Vert_2 \le 0, \quad \forall l' < l
```

**2.** **动力学可行性约束（Feasibility）**

**左右车轮速度与角加速度限幅：**

```math
\mathcal{G}_{\omega_{l(r)}}(\dot{q}_b, \ddot{q}_b) = \omega_{l(r)}^2 - \omega_{w,\max}^2 \le 0, \quad \mathcal{G}_{\alpha_{l(r)}}(\dot{q}_b, \ddot{q}_b, q_b^{(3)}) = \alpha_{l(r)}^2 - \alpha_{w,\max}^2 \le 0
```

**机械臂关节限幅：**

```math
q_{l,\min} \le q_l \le q_{l,\max}, \qquad
\dot{q}_l^2 \le \omega_{l,\max}^2, \qquad
\ddot{q}_l^2 \le \alpha_{l,\max}^2
```

**3.** **末端任务约束（Task）**

**末端位置容差：** $\mathcal{G}_{t_p}(q) = \Vert {}^{\mathcal{W}}p_e - {}^{\mathcal{W}}p_t \Vert_2 - d_p \le 0$

**末端姿态容差（由旋转矩阵迹求最小旋转轴角误差）：**

```math
\mathcal{G}_{t_o}(q) = \arccos\left(\frac{1}{2}\left(\mathrm{tr}({}^{\mathcal{W}}R_t^T \, {}^{\mathcal{W}}R_e) - 1\right)\right) - d_o \le 0
```

### 四、 实验设置与对比分析

REMANI-Planner 将 Hybrid A\*、分层 RRT\*-Connect、MINCO、多球体包络与 ESDF 避障组合成了一套完整的系统，针对窄道断连引入了局部全身重搜，并在仿真（矮桥洞消融、Cuboids/Bridge 对比）以及真机上跑通了闭环，工程落地价值高。

但是我看原文的实验设计，有点不严谨：

**消融实验只有一个：** 原文只切掉了“局部全身路径搜索（Local Whole-body Path Searching）”这一个模块做消融（桥高由 $0.7\text{ m}$ 压至 $0.4\text{ m}$）。但整套系统是多组件强耦合的工程方案，仅消融局部修复一环，其他组件的实际贡献无法衡量。

**对比基线不够对等：** 原文前端只比了全维 RRT\*-Connect，后端只比了不带时间分配与底盘非完整约束的 CHOMP。拿一套“全局引导 + 分层采样 + 局部重搜 + 时空优化”的完整系统去分别比单一采样器或纯梯度优化器，我感觉不是很合理。更合理的参照系应纳入工程上常用的**两阶段纯解耦基线**（底盘先导航至目标附近 + 机械臂 IK/规划）、高自由度下的 **OMPL 采样规划器**，以及近年主流的**全身 MPC** 方法，这块我补了一些，数据基本上没有量级上的差异、只是在特定环境下低净空、窄通道这种解耦规划直接出局，联合规划是唯一可行解，然后还有一些调参像 remani 自带 $0.10\text{ m}$ 软余量硬编进代价，所以即使执行有误差也不碰，然后做实验的时候发现了一些像局部 rrt 本该围绕中断搜索但代码将底盘采样边界直接扩成 $20\text{ m}$ 基本上 8 维全图撒点、时间 $600\text{ ms}$ 墙钟不真实等问题。

**横向可比性受限：** 受限于真机硬件构型与场地差异，移动操作领域本身缺乏统一公开的 benchmark（我查到在 remani 之后有多机器人多场地的但后续工作也都没有用），和各方法的优化侧重点也不同；为了更客观地评估这套框架，我在统一任务设置下补充了一些对比基线，代码与实验记录已整理至 https://github.com/helloaisvg/WBC：

$9$ 自由度 OMPL RRT-Connect；

两阶段解耦基线（基座导航到位后再做机械臂 IK 与规划）；

自研全身 MPC 等。

在对齐测试条件后，REMANI-Planner 与不同技术路线之间的性能取舍比原文展现得更加清晰。此外，我尝试在 REMANI 框架中引入了**可恢复机制（Recovery）与动态预测优化**，并同后续工作 `TopAY` 进行了对比测试：改进方案在纯规划耗时上优势不明显，但在卡死后的**全身恢复能力与整体任务完成率**上有切实提升。这也说明原框架在异常恢复与鲁棒性上还有很大的深挖空间，后续如果有机会我也计划沿着可恢复机制与动态场景规划继续往下探索。
