# 真机接入契约

## 频率分层

- 壳与平衡环：1 kHz；
- 全身规划与动作选择：100 Hz；
- 主动探边：每 80–100 个规划周期一次；
- 慢回路：每个班次或每个数据批次一次。

壳是无动态分配的常数时间函数，可直接放入 1 kHz 控制线程。规划线程
只提交候选命令；壳输出是唯一允许进入底层驱动的命令。

## 必须接上的硬件量

| 量 | 用途 |
|---|---|
| 驱动侧力矩、速度、位置硬限 | 形成不可覆盖的最终包络 |
| 关节位置与速度 | 关节边界和低惯量恢复姿态 |
| IMU roll 与角速度 | 支撑和身体失稳门控 |
| 轮速、偏航角速度 | 制动距离与横向耦合 |
| 深度/距离传感器净距 | 制动门控和碰撞前停止 |
| 足/轮支撑多边形 | 支撑域投影 |
| 夹爪载荷质量估计 | 横向预算和恢复策略 |
| 底盘/机械臂服务状态 | 恢复动作可执行性 |

## 部署步骤

1. 在底层驱动或安全 PLC 写入速度、力矩、位置和碰撞停止硬限。
2. 标定一阶速度响应时间与最大制动减速度。
3. 标定轮式支撑域、横向预算和恢复平衡动作幅值。
4. 用 `rwb_shell_spec` 的离散包络作为第一层出厂验收。
5. 在悬空、低速、空载状态注入极端命令，确认壳接管且无结构冲击。
6. 在料箱场景采集恢复试验，替换仿真标签源，其余数据接口不变。
7. 以三个指标作为放行条件：壳触发率可解释、边界扩张非零、不可逆
   事件率低于场景上限。

## 遥测接入

`src/closed_loop.cpp` 的 CSV 字段对应部署日志契约。真机节点写入同一
字段集合后，`rwb_curriculum` 与 `rwb_train --curriculum` 可直接消费。
状态字段来自命令执行前，动作字段来自壳投影前，避免状态动作错位。

## 场景扩张

达到三个指标后按以下顺序扩张：

1. 增加载荷质量与地面摩擦；
2. 增加扰动幅值与方向；
3. 更换料箱尺寸与质心；
4. 增加货架间距和转弯曲率；
5. 加入动态障碍与其他人员。

每次只扩张一个维度，保留前一组为对照，三指标不回退才进入下一组。
