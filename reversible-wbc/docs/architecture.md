# 架构

## 控制链

每个控制周期按固定顺序执行：

1. 名义规划器产生基座速度、转向、机械臂目标与平衡动作。
2. `SafetyShell::project` 把命令投影到冻结的硬边界。
3. 恢复性集成模型输出救援概率、认知不确定性和覆盖度。
4. `RecoverabilityGate` 在不可逆风险区切换到恢复动作；在边界窄带
   只收缩速度和转向，继续执行。
5. 主动探边器在候选动作中选择最接近恢复边界且不确定性高的一条。
6. 仿真或真机回流执行结果；新边界证书进入 `BoundaryBook`。
7. 探边结果直接更新模型的少量动作敏感参数。
8. 三指标与完整状态-动作遥测落盘。

学习模型没有改写壳的权力。`SafetyShell` 在启动时 `freeze()`，之后的
投影只依赖当前状态和冻结参数。

## 可逆性壳

壳位于 `include/rwb/safety_shell.hpp`，约束如下：

- 线速度、角速度、关节目标与平衡动作硬限；
- 关节硬行程内缩 0.055 rad；
- 一阶速度环对应的线/角加速度包络；
- 转弯速度与横向加速度联合预算；
- 摩擦锥保守占用率；
- 支撑域占用；
- 可用净距内的制动距离约束；
- 超包络状态直接进入恢复动作。

横向预算：

```text
lat_budget =
    max_lat_accel
    * clamp(friction / 1.1, 0.72, 1.12)
    * (1 - 0.20 * arm_extension - 0.012 * payload_mass_excess)

abs(v_target * omega_target) <= 0.94 * lat_budget
```

制动约束：

```text
stop_distance(v) = v^2 / (2 * stop_decel) + abs(v) * control_dt
available = obstacle_clearance - base_radius - collision_margin
```

当当前速度的制动距离超过可用净距，壳立刻给出恢复动作。接近边界但仍
可恢复时，只限制目标速度。

恢复动作同时执行：

- 基座速度归零；
- 小角速度回正；
- 机械臂收回到低惯量姿态；
- 依据 roll、roll rate 与外部扰动施加有限平衡动作。

## 可恢复性模型

模型输入为 17 维状态-动作特征：

| 组 | 内容 |
|---|---|
| 运动 | 线速度、角速度、线加速度、角加速度、横向加速度 |
| 身体 | 机械臂伸展、关节目标偏差、关节速度、roll、载荷倾角与角速度 |
| 环境 | 载荷质量、摩擦、障碍净距、外部扰动 |
| 动作 | 肩、肘目标 |

模型扩展为原始项、平方项、关键交互项、边界铰链项和三次风险项。五个
自助法逻辑回归成员共享输入展开，独立训练，用成员方差估计认知不确定性。

训练先保留 20% 数据做阈值标定。严格阈值取负样本分数的 90% 分位，
探边阈值取负样本分数的 75% 分位。模型评价与阈值适应来自留出集。

在线更新只作用于线加速度、角加速度、横向耦合、关节目标偏差、roll、
载荷倾角、障碍净距和偏置这八个参数，更新率为基础学习率的 3%，单参数
累计改变不超过 0.16。

## 主动探边

每个探边周期生成五个风险尺度，依次放大速度、转向和机械臂伸展。候选
必须高于探边硬地板。评分函数：

```text
score =
    1.25 * exp(-(p_rescue - target)^2 / 0.012)
  + 0.85 * epistemic_uncertainty
  + 0.16 * (risk_scale - 1)
```

选中的短时动作在物理壳内执行，同时用同一恢复策略得到可恢复标签。新
的量化状态-动作单元只有在命中近边界区或高不确定性区时才写入
`BoundaryBook`。扩张量定义为新证书数，不把重复访问算作扩张。

## 三指标

- 壳触发率：发生横向、支撑、制动或超包络硬介入的控制步占比；
- 可逆域扩张率：新增边界证书数 / 探边交互数；
- 任务级不可逆事件率：载荷倾覆、身体失稳、碰撞或越界导致终止的
  回合占比。

轨迹完成率和控制延迟是验收辅助指标，不替代三指标。

## 模块边界

| 文件 | 职责 |
|---|---|
| `src/safety_shell.cpp` | 构造安全投影与恢复命令 |
| `src/dynamics.cpp` | 仓库载物动力学、事件判定、恢复试验 |
| `src/monitor.cpp` | 集成模型、阈值标定、在线参数更新 |
| `src/policy.cpp` | 名义控制、探边、门控、边界证书 |
| `src/closed_loop.cpp` | 控制循环、遥测、探边回流 |
| `src/metrics.cpp` | 三指标、CSV/JSON/SVG/报告 |
| `apps/rwb_curriculum.cpp` | 失败窗口与边界证书采矿 |
